# Telegram-bot for EveEchoes corporation chat-group

EveEchoes game corporation telegram bot

Телеграм-бот для чат-групп корпораций игры EveEchoes

## Разработчику

### Особенности сборки

* Простая docker-compose сборка для Pyton 3.11 + PostgreSQL (см. [./docker-compose.yml](docker-compose.yml))

### 🚀 Быстрый старт

1. Убедитесь, что у вас установлены все [необходимые компоненты](./docs/dev_install_win10.md#-для-работы-понадобятся)
2. Следуйте [инструкции по установке](./docs/dev_install_win10.md#установка-проекта)
3. Запуск командой `docker compose up -d`, остановка командой `docker compose down`
